COMP200 Manual C
Overview

This repository contains the COMP200 Manual C project. It is intended to provide documentation, practical exercises, examples, and reference materials related to the course.

Repository Information

Project Objectives
Understand the fundamentals of C programming.
Develop problem-solving and logical thinking skills.
Practice writing, compiling, and executing C programs.
Understand variables, data types, operators, and control structures.
Apply functions, arrays, pointers, and other C programming concepts.

Getting Started
1. Clone the repository
bash
git clone https://github.com/ojijotom/COMP200-Manual.C.git

2. Open the project

Open the cloned project folder in CLion or your preferred C development environment.

3. Compile a C program

Using GCC:

bash
gcc main.c -o main

4. Run the program

On Windows:

bash
main.exe
